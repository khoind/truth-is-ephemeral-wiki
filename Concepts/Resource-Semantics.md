# Resource Semantics

## One-sentence definition

Resource semantics interprets a substructural proof inside a structural predicate logic by annotating each judgment with an explicit algebraic expression for exactly which resources justify it.

## Why the concept is needed

Structural intuitionistic propositional logic is decidable, while linear logic with exponentials can encode undecidable machines, so there can be no faithful translation of the whole latter into the former. Moving to intuitionistic **predicate** logic supplies enough expressiveness. Explicit resource indices then preserve linear or ordered accounting even though the target proof context itself is structural.

## Intuitive model

**Intuition.** A proposition is accompanied by a receipt. The surrounding notebook may copy entries freely, but a valid conclusion's receipt records exactly which tokens paid for it. The receipt algebra, not the target context discipline, enforces substructural use.

## Formal core

Write $A[ p ]$ for “$A$ is justified by resource expression $p$.” For linear logic, expressions form the free commutative monoid generated by labels $\alpha,\beta,\ldots$:

$$
p::=\epsilon\mid\alpha\mid p*q,
$$

with associativity, unit $\epsilon$, and commutativity, but no idempotence. Thus $\alpha*\beta=\beta*\alpha$, while $\alpha*\alpha\ne\alpha$. A judgment

$$
A_1[\alpha_1],\ldots,A_n[\alpha_n]\vdash C[p]
$$

has a structural antecedent; $p$ identifies the resources actually used. Linear adequacy relates $A_1,\ldots,A_n\vdash A$ to the annotated proof of $A[\alpha_1*\cdots*\alpha_n]$ with distinct labels, and conversely restricts the structural context to labels occurring in $p$.

Dropping commutativity yields an ordered resource monoid. An affine interpretation adds an order expressing that a conclusion may use fewer available resources.

## How to use/read it

Give every resource-bearing assumption a fresh label. Propagate products through multiplicative rules, require identical annotations through additive branches, and interpret $\epsilon$ as independence from linear resources. Do not infer usage from mere presence in the structural context; inspect the succedent annotation.

## Worked example

Derive $P\otimes Q$ from $P[\alpha],Q[\beta],R[\gamma]$.

1. Structural identity yields $P[\alpha],Q[\beta],R[\gamma]\vdash P[\alpha]$.
2. Identity also yields the same antecedent proving $Q[\beta]$.
3. Tensor right combines receipts: $P\otimes Q[\alpha*\beta]$.
4. $\gamma$ is absent from the receipt, so $R$ was not used even though it remains in the structural context.
5. The converse adequacy restriction selects only $P[\alpha]$ and $Q[\beta]$, recovering the linear sequent $P,Q\vdash P\otimes Q$.

Commutativity permits $\beta*\alpha$ as the same receipt; omitting either label would be invalid.

## Non-example or boundary case

If two distinct assumptions are both labeled $\alpha$, the expression no longer identifies a unique resource. The lecture's system presupposes unique labels and resource terms without repeated variables; it is not designed to count a particular resource twice.

## Key consequences

The translation separates structural proof management from substructural resource accounting. It clarifies validity as the empty receipt, supports ordered logic by changing the algebra, and enables an adequacy theorem rather than a one-way soundness claim.

It also gives a diagnostic method for proposed rules: calculate the receipt in every premise and check that a conclusion neither loses nor duplicates a label unless the chosen resource algebra explicitly authorizes that behavior.

## Common mistakes

- Treating $*$ as object-language tensor; it combines semantic resource labels.
- Assuming a structural antecedent occurrence was used merely because it is present.
- Adding idempotence $\alpha*\alpha=\alpha$ to the linear monoid.
- Reusing one label for distinct resources.
- Claiming a translation into decidable propositional intuitionistic logic.

## What to remember

- Resource usage is explicit in the annotation.
- Linear labels form a free commutative monoid.
- $\epsilon$ means no linear resource was used.
- Adequacy requires both translation directions.
- Change the resource algebra to model other regimes.
